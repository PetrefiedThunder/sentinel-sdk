16: ## Filing a bug
17: 
18: Open an issue at https://github.com/PetrefiedThunder/sentinel-sdk/issues
19: and include:
20: 
21: 1. SDK version (`python -c "import sentinel; print(sentinel.__version__)"`)
22: 2. Python version and OS
23: 3. A minimal reproducible example (10–20 lines)
24: 4. The full traceback / error message
25: 
26: ## Pull requests
27: 
28: 1. Open an issue first if it's a behavior change — saves you wasted work.
29: 2. Branch from `main`. Small, focused PRs over large ones.
30: 3. Add a test that fails before your fix and passes after.
31: 4. Run `pytest` and `ruff check .` before pushing.
32: 5. Update `CHANGELOG.md` under an `## [Unreleased]` heading.
33: 
34: ## Releasing (maintainers only)
35: 
36: 1. Bump `version` in `pyproject.toml`, `sentinel/__init__.py`,
37:    and the `USER_AGENT` constant in `sentinel/client.py`.
38: 2. Move `## [Unreleased]` notes into a versioned section in
39:    `CHANGELOG.md` with today's date.
40: 3. Commit, tag `vX.Y.Z`, push tags. GitHub Actions ships to PyPI via
41:    Trusted Publishing.
42: 
43: ## Security
44: 
45: If you find a security issue, please email security@regengine.co —
46: do **not** file a public GitHub issue.
47: 
48: ## Code of conduct
49: 
50: Be excellent to each other. Bigoted, harassing, or otherwise antisocial
51: behavior gets you removed from the project.

13: def _default_timeout() -> float:
14:     try:
15:         return float(os.environ.get("SENTINEL_TIMEOUT", "300"))
16:     except ValueError:

18:

23:

1: class SentinelError(Exception):
2:     """Base error for the Sentinel SDK."""
3: 
4: 
5: class SentinelConfigError(SentinelError):
6:     """Raised when the SDK is used without required configuration."""
7: 
8: 
9: class SentinelAPIError(SentinelError):
10:     """Raised when a Sentinel API request returns a non-2xx response."""
11: 
12:     def __init__(self, status_code: int, message: str = "", url: str | None = None):
13:         self.status_code = status_code
14:         self.url = url
15:         msg = f"Sentinel API {status_code}"
16:         if url:
17:             msg += f" {url}"
18:         if message:
19:             msg += f": {message}"
20:         super().__init__(msg)
21: 
22: 
23: class ApprovalRejected(SentinelError):
24:     """Raised when an approval request is rejected by an approver."""
25: 
26:     def __init__(self, reason: str = "", action_id: str | None = None):
27:         self.reason = reason
28:         self.action_id = action_id
29:         super().__init__(reason or "Approval rejected")
30: 
31: 
32: class ApprovalTimeout(SentinelError):
33:     """Raised when an approval request times out without a decision."""
34: 
35:     def __init__(self, action_id: str | None = None, timeout_seconds: float | None = None):
36:         self.action_id = action_id
37:         self.timeout_seconds = timeout_seconds
38:         msg = (
39:             f"Approval timed out after {timeout_seconds}s"
40:             if timeout_seconds
41:             else "Approval timed out"
42:         )
43:         super().__init__(msg)
